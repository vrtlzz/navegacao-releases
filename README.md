# Navegação: versões

Ficheiros de instalação (APK) da app Android **Navegação**. O código-fonte está num repositório privado.

- `version.json`: versão mais recente. A app lê este ficheiro para saber se há atualização.
- `apks/`: um APK por versão.

A app atualiza-se sozinha a partir daqui. Para instalar à mão, descarregue o APK mais recente em `apks/` e abra-o no telemóvel (Android 8.0 ou superior).
